How to install

01
Open the downloaded .dmg file
02
Drag Signal into your Applications folder
03
Open Terminal (search "Terminal" in Spotlight) and paste this command:
xattr -cr /Applications/Signal.app
Press Enter to run it. This clears the macOS quarantine flag.
04
Open Signal from Applications. It will launch normally.
05
Signal appears in your menu bar (top-right). You're done.
Why the terminal step?

Signal is distributed directly from this website, not the Mac App Store. macOS quarantines apps downloaded from the internet. The terminal command removes this flag so macOS lets Signal run. This is a one-time step — completely safe, and standard for independent Mac software.
